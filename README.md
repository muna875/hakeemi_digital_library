# Hakeemi Digital Library

Offline-first bilingual (Urdu & English) Flutter application for maintaining four permanent personal books with automatic dynamic pagination, structured Nuskha management, SQLite FTS5 search, ZIP backup/restore, and print-ready PDF publishing.

## Quick Start (Local Machine with Flutter SDK >= 3.3.0)

```bash
flutter pub get
dart format lib test
flutter analyze
flutter test
flutter build apk --debug
```

Debug APK output path after building:
`build/app/outputs/flutter-apk/app-debug.apk`
